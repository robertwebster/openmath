# Integration Techniques — Worked Examples

## Example 1: Integration by parts — choosing $u$ and $dv$

**Problem:** Evaluate $\displaystyle\int_0^1 x^2 e^x\,dx$.

**Solution:**

Apply integration by parts twice. The rule is $\displaystyle\int u\,dv = uv - \int v\,du$.

**First application:** Let $u = x^2$, $dv = e^x\,dx$, so $du = 2x\,dx$, $v = e^x$.
$$\int_0^1 x^2 e^x\,dx = \Big[x^2 e^x\Big]_0^1 - 2\int_0^1 x e^x\,dx = e - 2\int_0^1 x e^x\,dx$$

**Second application** on $\int_0^1 xe^x\,dx$: Let $u = x$, $dv = e^x\,dx$.
$$\int_0^1 x e^x\,dx = \Big[xe^x\Big]_0^1 - \int_0^1 e^x\,dx = e - \Big[e^x\Big]_0^1 = e - (e-1) = 1$$

**Combining:**
$$\int_0^1 x^2 e^x\,dx = e - 2(1) = e - 2 \approx 0.72$$

## Example 2: Partial fractions with a repeated linear factor

**Problem:** Evaluate $\displaystyle\int_1^2 \frac{1}{x(x+1)^2}\,dx$.

**Solution:**

Decompose using partial fractions:
$$\frac{1}{x(x+1)^2} = \frac{A}{x} + \frac{B}{x+1} + \frac{C}{(x+1)^2}$$

Multiplying both sides by $x(x+1)^2$:
$$1 = A(x+1)^2 + Bx(x+1) + Cx$$

- Setting $x = 0$: $1 = A$
- Setting $x = -1$: $1 = -C$, so $C = -1$
- Comparing coefficients of $x^2$: $0 = A + B$, so $B = -1$

$$\frac{1}{x(x+1)^2} = \frac{1}{x} - \frac{1}{x+1} - \frac{1}{(x+1)^2}$$

Integrating:
$$\left[\ln x - \ln(x+1) + \frac{1}{x+1}\right]_1^2 = \left(\ln 2 - \ln 3 + \frac{1}{3}\right) - \left(0 - \ln 2 + \frac{1}{2}\right) = \ln\frac{4}{3} - \frac{1}{6} \approx 0.12$$

## Example 3: The Weierstrass ($t$-)substitution

**Problem:** Evaluate $\displaystyle\int_0^{\pi/2} \frac{1}{2 + \cos x}\,dx$ using $t = \tan\!\left(\tfrac{x}{2}\right)$.

**Solution:**

With $t = \tan(x/2)$:
$$\cos x = \frac{1-t^2}{1+t^2}, \qquad dx = \frac{2}{1+t^2}\,dt$$

When $x = 0$, $t = 0$; when $x = \pi/2$, $t = 1$.

$$\int_0^1 \frac{1}{2 + \frac{1-t^2}{1+t^2}} \cdot \frac{2}{1+t^2}\,dt = \int_0^1 \frac{1+t^2}{2(1+t^2) + (1-t^2)} \cdot \frac{2}{1+t^2}\,dt$$

$$= \int_0^1 \frac{2}{t^2 + 3}\,dt = \frac{2}{\sqrt{3}}\Big[\arctan\!\left(\tfrac{t}{\sqrt{3}}\right)\Big]_0^1 = \frac{2}{\sqrt{3}} \cdot \frac{\pi}{6} = \frac{\pi}{3\sqrt{3}} \approx 0.605$$
