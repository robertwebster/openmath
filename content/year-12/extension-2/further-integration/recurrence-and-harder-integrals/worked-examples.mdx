# Recurrence and Harder Integrals — Worked Examples

## Example 1: Deriving a reduction formula

**Problem:** Let $I_n = \displaystyle\int_0^{\pi/2} \sin^n x\,dx$. Derive the reduction formula $I_n = \dfrac{n-1}{n}\,I_{n-2}$.

**Solution:**

Write $\sin^n x = \sin^{n-1}x \cdot \sin x$ and apply integration by parts.

Let $u = \sin^{n-1}x$ and $dv = \sin x\,dx$, so $du = (n-1)\sin^{n-2}x\cos x\,dx$ and $v = -\cos x$.

$$I_n = \Big[-\sin^{n-1}x\cos x\Big]_0^{\pi/2} + (n-1)\int_0^{\pi/2}\sin^{n-2}x\cos^2 x\,dx$$

The boundary term vanishes at both limits. Using $\cos^2 x = 1 - \sin^2 x$:

$$I_n = (n-1)\int_0^{\pi/2}\sin^{n-2}x(1 - \sin^2 x)\,dx = (n-1)(I_{n-2} - I_n)$$

Solving for $I_n$:
$$I_n + (n-1)I_n = (n-1)I_{n-2} \implies n\,I_n = (n-1)I_{n-2}$$
$$\boxed{I_n = \frac{n-1}{n}\,I_{n-2}}$$

## Example 2: Applying a reduction formula

**Problem:** Evaluate $\displaystyle\int_0^{\pi/2} \sin^5 x\,dx$ using $I_n = \dfrac{n-1}{n}\,I_{n-2}$ with $I_1 = 1$.

**Solution:**

Apply the formula twice, stepping down by 2 each time:

$$I_3 = \frac{2}{3}\,I_1 = \frac{2}{3}\cdot 1 = \frac{2}{3}$$

$$I_5 = \frac{4}{5}\,I_3 = \frac{4}{5}\cdot\frac{2}{3} = \frac{8}{15}$$

**Check:** $\frac{8}{15} \approx 0.533$. This is less than $I_4 \approx 0.589$ and greater than $I_6 \approx 0.491$, which is consistent since $\{I_n\}$ is decreasing. ✓

## Example 3: Choosing the right technique

**Problem:** Evaluate $\displaystyle\int_1^e \frac{(\ln x)^3}{x}\,dx$.

**Solution:**

The integrand has the form $[\text{function of }\ln x]\cdot\dfrac{1}{x}$, which suggests the substitution $u = \ln x$.

Let $u = \ln x$, so $du = \dfrac{1}{x}\,dx$.

When $x = 1$: $u = 0$. When $x = e$: $u = 1$.

$$\int_1^e \frac{(\ln x)^3}{x}\,dx = \int_0^1 u^3\,du = \left[\frac{u^4}{4}\right]_0^1 = \frac{1}{4}$$

**Key insight:** Always scan for the form $f'(x)\cdot g(f(x))$ before reaching for integration by parts — substitution is faster when it applies.
