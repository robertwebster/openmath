# Vector equations of lines and curves — Worked examples

A line through point $A$ with position vector $\mathbf{a}$, running parallel to direction vector $\mathbf{b}$, has the vector equation

$$\mathbf{r} = \mathbf{a}+\lambda\mathbf{b}, \quad \lambda \in \mathbb{R}$$

The equivalent **parametric form** writes $x$, $y$, $z$ as separate equations in $\lambda$.

---

## Example 1 — Reading off a point and converting to parametric form

**A line has equation $\mathbf{r} = (2,-1,3)+\lambda(1,2,-1)$. Find the point where $\lambda = 3$, and write parametric equations.**

**Parametric equations:**
$$x = 2+\lambda, \quad y = -1+2\lambda, \quad z = 3-\lambda$$

**At $\lambda = 3$:**
$$x = 2+3 = 5, \quad y = -1+6 = 5, \quad z = 3-3 = 0$$

The point is $(5, 5, 0)$.

---

## Example 2 — Intersection of two lines

**Determine whether $L_1: \mathbf{r} = (1,2,3)+\lambda(2,0,1)$ and $L_2: \mathbf{r} = (3,2,4)+\mu(-1,0,2)$ intersect, and if so find the point.**

Write parametric equations and equate:

| | $L_1$ | $L_2$ |
|---|---|---|
| $x$ | $1+2\lambda$ | $3-\mu$ |
| $y$ | $2$ | $2$ |
| $z$ | $3+\lambda$ | $4+2\mu$ |

The $y$-equations match automatically.

**From $x$:** $1+2\lambda = 3-\mu \implies 2\lambda+\mu = 2$ … (i)

**From $z$:** $3+\lambda = 4+2\mu \implies \lambda-2\mu = 1$ … (ii)

Solve: from (ii), $\lambda = 1+2\mu$. Sub into (i): $2+4\mu+\mu = 2 \implies \mu = 0$, $\lambda = 1$.

**Intersection at** $(1+2, 2, 3+1) = (3, 2, 4)$ — verified on $L_2$ with $\mu = 0$ ✓

## Example 3 — Identifying skew lines

**Show that $L_1: \mathbf{r} = (0,0,0)+\lambda(1,0,0)$ and $L_2: \mathbf{r} = (0,1,1)+\mu(0,1,0)$ are skew.**

$L_1$: $x = \lambda$, $y = 0$, $z = 0$
$L_2$: $x = 0$, $y = 1+\mu$, $z = 1$

**Check parallel:** $(1,0,0)$ and $(0,1,0)$ are not scalar multiples — not parallel.

**Check intersection:**
- $z$: $L_1$ always has $z = 0$; $L_2$ always has $z = 1$. These can never be equal.

No solution exists, so the lines **do not intersect**. Since they are also not parallel, they are **skew**.
