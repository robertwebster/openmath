# Anti-differentiation

## Example 1 — Using the power rule and an initial condition

**Problem:** A function $F(x)$ satisfies $F'(x) = 4x^3 - 6x$ and $F(1) = 2$. Find $F(x)$.

**Step 1 — Find the general antiderivative.**

Apply the power rule $\displaystyle\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$ to each term:

$$F(x) = \int (4x^3 - 6x)\,dx = x^4 - 3x^2 + C$$

**Step 2 — Use the initial condition to find $C$.**

$$F(1) = 1^4 - 3(1)^2 + C = 1 - 3 + C = -2 + C = 2$$

So $C = 4$.

**Step 3 — Write the particular solution.**

$$F(x) = x^4 - 3x^2 + 4$$

## Example 2 — Integrating exponential and reciprocal functions

**Problem:** Find $\displaystyle\int \!\left(e^{5x} + \frac{4}{x}\right)dx$ for $x > 0$.

**Step 1 — Integrate $e^{5x}$.**

Using the standard result $\displaystyle\int e^{ax}\,dx = \dfrac{e^{ax}}{a} + C$:

$$\int e^{5x}\,dx = \frac{e^{5x}}{5}$$

**Step 2 — Integrate $\dfrac{4}{x}$.**

$$\int \frac{4}{x}\,dx = 4\ln x$$

**Step 3 — Combine.**

$$\int \!\left(e^{5x} + \frac{4}{x}\right)dx = \frac{e^{5x}}{5} + 4\ln x + C$$

## Example 3 — Reverse chain rule

**Problem:** Find $\displaystyle\int 6x^2(x^3 - 1)^4\,dx$.

**Step 1 — Spot the pattern.**

Notice that $6x^2$ is the derivative of $x^3 - 1$. This is the reverse chain rule structure: $\displaystyle\int f'(u)\cdot u'\,dx$ where $u = x^3 - 1$.

**Step 2 — Let $u = x^3 - 1$.**

$$\frac{du}{dx} = 3x^2 \quad \Rightarrow \quad 6x^2\,dx = 2\,du$$

**Step 3 — Substitute and integrate.**

$$\int 6x^2(x^3-1)^4\,dx = \int 2u^4\,du = \frac{2u^5}{5} + C$$

**Step 4 — Back-substitute.**

$$= \frac{2(x^3-1)^5}{5} + C$$

Check by differentiating: $\dfrac{d}{dx}\!\left[\dfrac{2(x^3-1)^5}{5}\right] = \dfrac{2 \cdot 5(x^3-1)^4 \cdot 3x^2}{5} = 6x^2(x^3-1)^4$ ✓
