# Differentiating exponential and logarithmic functions

## Example 1 — Differentiating $e^{f(x)}$ using the chain rule

**Problem:** Find $\dfrac{d}{dx}\left(e^{4x - 1}\right)$.

**Step 1 — Identify the inner function.**

The outer function is $e^u$ and the inner function is $u = 4x - 1$.

**Step 2 — Differentiate the inner function.**

$$\frac{du}{dx} = 4$$

**Step 3 — Apply the chain rule.**

$$\frac{d}{dx}\left(e^{f(x)}\right) = f'(x)\,e^{f(x)}$$

$$\frac{d}{dx}\left(e^{4x-1}\right) = 4e^{4x-1}$$

## Example 2 — Differentiating $\ln f(x)$ using the chain rule

**Problem:** Find $\dfrac{d}{dx}\left(\ln(x^2 + 3x)\right)$.

**Step 1 — Identify $f(x)$ and find $f'(x)$.**

$$f(x) = x^2 + 3x \quad \Rightarrow \quad f'(x) = 2x + 3$$

**Step 2 — Apply the standard result.**

$$\frac{d}{dx}\left(\ln f(x)\right) = \frac{f'(x)}{f(x)}$$

$$\frac{d}{dx}\left(\ln(x^2 + 3x)\right) = \frac{2x + 3}{x^2 + 3x}$$

This can be factored as $\dfrac{2x+3}{x(x+3)}$, but either form is acceptable.

## Example 3 — Finding a gradient and tangent equation

**Problem:** Find the equation of the tangent to $y = 3e^{2x}$ at the point where $x = 0$.

**Step 1 — Find the point on the curve.**

At $x = 0$: $y = 3e^0 = 3 \times 1 = 3$. Point: $(0,\,3)$.

**Step 2 — Find the gradient using the derivative.**

$$\frac{dy}{dx} = 3 \times 2\,e^{2x} = 6e^{2x}$$

At $x = 0$: $\dfrac{dy}{dx} = 6e^0 = 6$.

**Step 3 — Write the tangent equation.**

Using $y - y_1 = m(x - x_1)$ with $m = 6$ and $(x_1, y_1) = (0, 3)$:

$$y - 3 = 6(x - 0)$$
$$y = 6x + 3$$
