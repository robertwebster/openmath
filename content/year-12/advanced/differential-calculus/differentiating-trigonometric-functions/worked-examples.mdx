# Differentiating trigonometric functions

## Example 1 — Standard derivatives

The three fundamental results (all angles in radians):

$$\frac{d}{dx}(\sin x) = \cos x \qquad \frac{d}{dx}(\cos x) = -\sin x \qquad \frac{d}{dx}(\tan x) = \sec^2 x$$

**Problem:** Find $\dfrac{dy}{dx}$ for $y = 2\sin x - 3\cos x$.

$$\frac{dy}{dx} = 2\cos x - 3 \times (-\sin x) = 2\cos x + 3\sin x$$

## Example 2 — Chain rule with trigonometric functions

**Problem:** Find $\dfrac{d}{dx}\left(\cos(4x - \pi)\right)$.

**Step 1 — Identify the inner function.**

Inner function: $u = 4x - \pi$, so $\dfrac{du}{dx} = 4$.

**Step 2 — Differentiate using the chain rule.**

$$\frac{d}{dx}(\cos u) = -\sin u \cdot \frac{du}{dx}$$

$$\frac{d}{dx}\!\left(\cos(4x - \pi)\right) = -\sin(4x - \pi) \times 4 = -4\sin(4x - \pi)$$

## Example 3 — Finding stationary points

**Problem:** Find the stationary points of $y = \sin(2x)$ for $0 \leq x \leq \pi$.

**Step 1 — Differentiate.**

$$\frac{dy}{dx} = 2\cos(2x)$$

**Step 2 — Set the derivative equal to zero.**

$$2\cos(2x) = 0 \implies \cos(2x) = 0$$

**Step 3 — Solve for $x$.**

$2x = \dfrac{\pi}{2}$ or $2x = \dfrac{3\pi}{2}$ (within $0 \leq 2x \leq 2\pi$)

$$x = \frac{\pi}{4} \quad \text{or} \quad x = \frac{3\pi}{4}$$

**Step 4 — Find the $y$-values.**

At $x = \dfrac{\pi}{4}$: $y = \sin\!\left(\dfrac{\pi}{2}\right) = 1$ (maximum).

At $x = \dfrac{3\pi}{4}$: $y = \sin\!\left(\dfrac{3\pi}{2}\right) = -1$ (minimum).
