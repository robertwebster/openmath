# The critical path — worked examples

## Example 1: Identifying the critical path

A project has the following activities. Find the minimum completion time and identify the critical path.

| Activity | Predecessors | Duration (days) |
|---|---|---|
| A | — | 5 |
| B | — | 3 |
| C | A | 4 |
| D | A, B | 6 |
| E | C, D | 3 |

<WorkedExample>
  <Step>**Forward scan** — find EST and EFT for each activity. Activities with no predecessors start at EST = 0.
  $$\text{EFT}_A = 0 + 5 = 5,\quad \text{EFT}_B = 0 + 3 = 3$$</Step>
  <Step>Activities C and D follow A (and B for D):
  $$\text{EST}_C = 5,\quad \text{EFT}_C = 5 + 4 = 9$$
  $$\text{EST}_D = \max(\text{EFT}_A, \text{EFT}_B) = \max(5, 3) = 5,\quad \text{EFT}_D = 5 + 6 = 11$$</Step>
  <Step>Activity E requires both C and D to finish:
  $$\text{EST}_E = \max(9, 11) = 11,\quad \text{EFT}_E = 11 + 3 = 14$$
  Minimum project completion time = **14 days**.</Step>
  <Step>**Backward scan** — set LST of the last activity so the project finishes exactly on time.
  $$\text{LST}_E = 14 - 3 = 11$$
  $$\text{LST}_D = 11 - 6 = 5,\quad \text{LST}_C = 11 - 4 = 7$$
  $$\text{LST}_A = \min(\text{LST}_C, \text{LST}_D) - \text{dur}_A = \min(7, 5) - 5 = 5 - 5 = 0$$
  $$\text{LST}_B = \text{LST}_D - \text{dur}_B = 5 - 3 = 2$$</Step>
  <Step>**Calculate float** (Float = LST − EST) and identify the critical path (float = 0):

  | Activity | EST | LST | Float |
  |---|---|---|---|
  | A | 0 | 0 | **0** ← critical |
  | B | 0 | 2 | 2 |
  | C | 5 | 7 | 2 |
  | D | 5 | 5 | **0** ← critical |
  | E | 11 | 11 | **0** ← critical |

  The critical path is **A → D → E**, with duration $5 + 6 + 3 = 14$ days.</Step>
</WorkedExample>

## Example 2: Effect of a delay on a critical activity

Using the project above (critical path A → D → E, minimum completion time 14 days), activity D is delayed by 4 days. What is the new minimum completion time?

<WorkedExample>
  <Step>Activity D is on the critical path, so it has zero float. Any delay to D adds directly to the project duration.</Step>
  <Step>$$\text{New completion time} = 14 + 4 = 18 \text{ days}$$</Step>
  <Step>The project is now expected to take **18 days** minimum. If Robert wants to recover the original 14-day finish, another activity on the critical path must be shortened by 4 days.</Step>
</WorkedExample>

## Example 3: Effect of a delay on a non-critical activity

Activity B (float = 2 days) is delayed by 5 days. By how many days is the project delayed?

<WorkedExample>
  <Step>Activity B has 2 days of float — it can absorb up to 2 days of delay without affecting the project finish.</Step>
  <Step>The delay of 5 days exceeds the float by $5 - 2 = 3$ days. The excess delay flows through to the project finish.</Step>
  <Step>$$\text{Project delay} = 5 - 2 = 3 \text{ days}$$
  The new minimum completion time would be $14 + 3 = 17$ days.</Step>
  <Step>Note: once activity B is delayed by more than 2 days, it becomes critical — it now has zero float and joins the critical path.</Step>
</WorkedExample>
