# Standard integral forms — Worked examples

The Extension 1 syllabus introduces three new families of standard integrals. Each comes from reversing a known derivative.

| Integral | Result | Comes from |
|---|---|---|
| $\displaystyle\int \frac{1}{\sqrt{a^2-x^2}}\,dx$ | $\sin^{-1}\!\left(\dfrac{x}{a}\right) + C$ | $\frac{d}{dx}\sin^{-1}\!\left(\dfrac{x}{a}\right) = \dfrac{1}{\sqrt{a^2-x^2}}$ |
| $\displaystyle\int \frac{1}{a^2+x^2}\,dx$ | $\dfrac{1}{a}\tan^{-1}\!\left(\dfrac{x}{a}\right) + C$ | $\frac{d}{dx}\tan^{-1}\!\left(\dfrac{x}{a}\right) = \dfrac{a}{a^2+x^2}$ |
| $\displaystyle\int \sin^2 x\,dx$ | $\dfrac{x}{2} - \dfrac{\sin 2x}{4} + C$ | double-angle: $\sin^2 x = \dfrac{1-\cos 2x}{2}$ |
| $\displaystyle\int \cos^2 x\,dx$ | $\dfrac{x}{2} + \dfrac{\sin 2x}{4} + C$ | double-angle: $\cos^2 x = \dfrac{1+\cos 2x}{2}$ |

---

## Example 1 — Inverse-sine form

**Find $\displaystyle\int \frac{5}{\sqrt{25-x^2}}\,dx$.**

**Step 1 — Identify $a$.**

Write $25 - x^2 = 5^2 - x^2$, so $a = 5$.

**Step 2 — Apply the standard form.**

$$\int \frac{5}{\sqrt{25-x^2}}\,dx = 5\int \frac{1}{\sqrt{5^2-x^2}}\,dx = 5\sin^{-1}\!\left(\frac{x}{5}\right) + C$$

> **Check by differentiating:** $\frac{d}{dx}\left[5\sin^{-1}\!\left(\frac{x}{5}\right)\right] = 5 \cdot \frac{1/5}{\sqrt{1-(x/5)^2}} = \frac{1}{\sqrt{1-x^2/25}} = \frac{5}{\sqrt{25-x^2}}$ ✓

## Example 2 — Inverse-tangent form (definite integral)

**Evaluate $\displaystyle\int_0^3 \frac{1}{9+x^2}\,dx$.**

**Step 1 — Identify $a$.**

$9 + x^2 = 3^2 + x^2$, so $a = 3$.

**Step 2 — Apply the standard form.**

$$\int_0^3 \frac{1}{9+x^2}\,dx = \frac{1}{3}\left[\tan^{-1}\!\left(\frac{x}{3}\right)\right]_0^3$$

**Step 3 — Substitute limits.**

$$= \frac{1}{3}\left(\tan^{-1}(1) - \tan^{-1}(0)\right) = \frac{1}{3}\left(\frac{\pi}{4} - 0\right) = \frac{\pi}{12}$$

---

## Example 3 — Double-angle substitution for $\cos^2 x$

**Evaluate $\displaystyle\int_0^{\pi/3} \cos^2 x\,dx$.**

**Step 1 — Use the double-angle identity.**

$$\cos^2 x = \frac{1+\cos 2x}{2}$$

**Step 2 — Integrate.**

$$\int_0^{\pi/3}\cos^2 x\,dx = \int_0^{\pi/3}\frac{1+\cos 2x}{2}\,dx = \left[\frac{x}{2}+\frac{\sin 2x}{4}\right]_0^{\pi/3}$$

**Step 3 — Substitute limits.**

$$= \left(\frac{\pi/3}{2}+\frac{\sin(2\pi/3)}{4}\right) - (0+0) = \frac{\pi}{6}+\frac{\sqrt{3}/2}{4} = \frac{\pi}{6}+\frac{\sqrt{3}}{8}$$

$$\approx 0.5236 + 0.2165 = 0.7401$$

> **Common error:** forgetting to halve the coefficient when differentiating $\sin 2x$ — always confirm $\frac{d}{dx}\left(\frac{\sin 2x}{4}\right) = \frac{2\cos 2x}{4} = \frac{\cos 2x}{2}$ ✓
