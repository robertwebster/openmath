# Inverse trig functions

## Example 1 — Evaluating inverse trig functions at exact values

**Problem:** Find the exact value of each of the following in radians.

(a) $\sin^{-1}\!\left(\dfrac{\sqrt{3}}{2}\right)$  
(b) $\cos^{-1}\!\left(-\dfrac{\sqrt{2}}{2}\right)$  
(c) $\tan^{-1}\!\left(\dfrac{1}{\sqrt{3}}\right)$

**Key idea:** Each inverse trig function has a restricted range. You need to find the angle *in that range* whose trig value matches the input.

| Function | Domain | Range |
|----------|--------|-------|
| $\sin^{-1}(x)$ | $[-1, 1]$ | $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ |
| $\cos^{-1}(x)$ | $[-1, 1]$ | $[0, \pi]$ |
| $\tan^{-1}(x)$ | $\mathbb{R}$ | $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ |

**Part (a):** $\sin^{-1}\!\left(\dfrac{\sqrt{3}}{2}\right)$

We need $\theta \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ with $\sin\theta = \dfrac{\sqrt{3}}{2}$.

From the special triangle: $\sin\!\left(\dfrac{\pi}{3}\right) = \dfrac{\sqrt{3}}{2}$, and $\dfrac{\pi}{3} \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.

$$\sin^{-1}\!\left(\frac{\sqrt{3}}{2}\right) = \frac{\pi}{3}$$

**Part (b):** $\cos^{-1}\!\left(-\dfrac{\sqrt{2}}{2}\right)$

We need $\theta \in [0, \pi]$ with $\cos\theta = -\dfrac{\sqrt{2}}{2}$.

Since $\cos\!\left(\dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{2}$, and cosine is negative in the second quadrant:

$$\cos\!\left(\pi - \frac{\pi}{4}\right) = \cos\!\left(\frac{3\pi}{4}\right) = -\frac{\sqrt{2}}{2}$$

And $\dfrac{3\pi}{4} \in [0, \pi]$, so $\cos^{-1}\!\left(-\dfrac{\sqrt{2}}{2}\right) = \dfrac{3\pi}{4}$.

**Part (c):** $\tan^{-1}\!\left(\dfrac{1}{\sqrt{3}}\right)$

We need $\theta \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ with $\tan\theta = \dfrac{1}{\sqrt{3}}$.

From the special triangle: $\tan\!\left(\dfrac{\pi}{6}\right) = \dfrac{1}{\sqrt{3}}$, and $\dfrac{\pi}{6} \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$.

$$\tan^{-1}\!\left(\frac{1}{\sqrt{3}}\right) = \frac{\pi}{6}$$

## Example 2 — Domain restrictions and the composition $\sin^{-1}(\sin(\theta))$

**Problem:** Evaluate $\sin^{-1}\!\left(\sin\!\left(\dfrac{7\pi}{6}\right)\right)$.

**Step 1 — Evaluate $\sin\!\left(\dfrac{7\pi}{6}\right)$.**

$\dfrac{7\pi}{6}$ is in the third quadrant ($\pi < \dfrac{7\pi}{6} < \dfrac{3\pi}{2}$).

$$\sin\!\left(\frac{7\pi}{6}\right) = -\sin\!\left(\frac{\pi}{6}\right) = -\frac{1}{2}$$

**Step 2 — Apply $\sin^{-1}$.**

$$\sin^{-1}\!\left(-\frac{1}{2}\right) = -\frac{\pi}{6}$$

(Since $-\dfrac{\pi}{6} \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ and $\sin\!\left(-\dfrac{\pi}{6}\right) = -\dfrac{1}{2}$.)

**Answer:** $\sin^{-1}\!\left(\sin\!\left(\dfrac{7\pi}{6}\right)\right) = -\dfrac{\pi}{6}$

**Why not $\dfrac{7\pi}{6}$?**  Because $\sin^{-1}$ always returns a value in $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$, and $\dfrac{7\pi}{6}$ is outside that range. The identity $\sin^{-1}(\sin(\theta)) = \theta$ only holds when $\theta \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$.

## Example 3 — Using inverse trig in a composition

**Problem:** Find the exact value of $\tan\!\left(\sin^{-1}\!\left(-\dfrac{5}{13}\right)\right)$.

**Step 1 — Let $\theta = \sin^{-1}\!\left(-\dfrac{5}{13}\right)$.**

Then $\sin\theta = -\dfrac{5}{13}$ and $\theta \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$. Since $\sin\theta < 0$, we have $\theta \in \left[-\dfrac{\pi}{2}, 0\right)$, so $\cos\theta > 0$.

**Step 2 — Find $\cos\theta$ using the Pythagorean identity.**

$$\cos^2\theta = 1 - \sin^2\theta = 1 - \frac{25}{169} = \frac{144}{169}$$

$$\cos\theta = \frac{12}{13} \quad (\text{positive since } \theta \in \left[-\tfrac{\pi}{2}, 0\right))$$

**Step 3 — Find $\tan\theta$.**

$$\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{-5/13}{12/13} = -\frac{5}{12}$$

**Answer:** $\tan\!\left(\sin^{-1}\!\left(-\dfrac{5}{13}\right)\right) = -\dfrac{5}{12}$
