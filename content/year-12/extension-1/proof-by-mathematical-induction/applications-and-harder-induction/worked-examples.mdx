# Applications and harder induction — Worked examples

These examples extend the basic induction template to three new contexts: geometric series, inequalities, and recursive sequences. The three-part structure (base case → inductive hypothesis → inductive step) is identical to the basic pattern.

---

## Example 1 — Inequality proof (Bernoulli's inequality)

**Prove that $(1 + x)^n \geq 1 + nx$ for all integers $n \geq 1$ and all $x > -1$.**

**Base case** ($n = 1$):

$(1 + x)^1 = 1 + x = 1 + 1 \cdot x$. Equality holds. ✓

**Inductive hypothesis:** Assume true for $n = m$: $(1 + x)^m \geq 1 + mx$ for all $x > -1$.

**Inductive step:** Prove true for $n = m + 1$, i.e., show $(1+x)^{m+1} \geq 1 + (m+1)x$.

Since $x > -1$, we have $1 + x > 0$. Multiplying both sides of the inductive hypothesis by $(1 + x)$:

$$(1+x)^{m+1} = (1+x)(1+x)^m \geq (1+x)(1+mx)$$

Expanding:

$$(1+x)(1+mx) = 1 + mx + x + mx^2 = 1 + (m+1)x + mx^2$$

Since $mx^2 \geq 0$:

$$(1+x)^{m+1} \geq 1 + (m+1)x + mx^2 \geq 1 + (m+1)x$$

This is the required inequality. ✓

**Conclusion:** By the principle of mathematical induction, $(1 + x)^n \geq 1 + nx$ for all $n \geq 1$ and $x > -1$. $\square$

> **Key technique:** When proving an inequality by induction, you often need to show that an expression *at least as large as* the inductive hypothesis is *at least as large as* the target. Here, the extra $mx^2$ term is non-negative, so it can be safely dropped without weakening the inequality.

## Example 2 — Recursive sequence

**A sequence is defined by $a_1 = 2$ and $a_{n+1} = 2a_n + 1$. Prove that $a_n = 3 \cdot 2^{n-1} - 1$ for all $n \geq 1$.**

First, check the formula makes sense:
- $a_1 = 3 \cdot 1 - 1 = 2$ ✓  
- $a_2 = 2(2) + 1 = 5 = 3 \cdot 2 - 1 = 5$ ✓

**Base case** ($n = 1$):

RHS $= 3 \cdot 2^0 - 1 = 3 - 1 = 2 = a_1$. ✓

**Inductive hypothesis:** Assume $a_m = 3 \cdot 2^{m-1} - 1$.

**Inductive step:** Show $a_{m+1} = 3 \cdot 2^m - 1$.

Using the recurrence relation:

$$a_{m+1} = 2a_m + 1 = 2(3 \cdot 2^{m-1} - 1) + 1 = 3 \cdot 2^m - 2 + 1 = 3 \cdot 2^m - 1$$

This equals $3 \cdot 2^{(m+1)-1} - 1$, the formula for $n = m+1$. ✓

**Conclusion:** By the principle of mathematical induction, $a_n = 3 \cdot 2^{n-1} - 1$ for all $n \geq 1$. $\square$

> **Strategy for recursive sequences:** Substitute the closed-form formula for $a_m$ directly into the recurrence relation. The goal is to reach the closed form for $n = m+1$ after simplification.

## Example 3 — Inequality with a non-standard base case

**Prove that $n! > 2^n$ for all integers $n \geq 4$.**

Note: the statement is *false* for $n = 1, 2, 3$ (since $1 < 2$, $2 < 4$, $6 < 8$), so the base case must be $n = 4$.

**Base case** ($n = 4$):

$4! = 24$ and $2^4 = 16$. Since $24 > 16$, the statement holds. ✓

**Inductive hypothesis:** Assume $m! > 2^m$ for some $m \geq 4$.

**Inductive step:** Show $(m+1)! > 2^{m+1}$.

Since $m \geq 4$, we have $m + 1 \geq 5$, so in particular $m + 1 > 2$. Using the inductive hypothesis:

$$(m+1)! = (m+1) \cdot m! > (m+1) \cdot 2^m > 2 \cdot 2^m = 2^{m+1}$$

So $(m+1)! > 2^{m+1}$. ✓

**Conclusion:** By the principle of mathematical induction, $n! > 2^n$ for all integers $n \geq 4$. $\square$

> **Common pitfall:** Always state the base case explicitly and verify it. If the base case is not $n = 1$, make sure the problem says "for all $n \geq k$" for the appropriate starting value $k$. The induction only guarantees the result from the base case onward.
