# Mathematical induction — Worked examples

Mathematical induction is a method of proof for statements about **all positive integers** (or all integers from some base case). Every induction proof has the same three-part structure:

1. **Base case:** Verify the statement is true for the smallest value (usually $n = 1$).
2. **Inductive hypothesis:** Assume the statement is true for $n = m$ (some arbitrary integer $m \geq 1$).
3. **Inductive step:** Using the hypothesis, prove the statement is true for $n = m + 1$.

The logic: if the first domino falls (base case), and each domino knocks over the next (inductive step), then all dominoes fall.

---

## Example 1 — Summation formula

**Prove that $\displaystyle\sum_{k=1}^{n} k = \dfrac{n(n+1)}{2}$ for all integers $n \geq 1$.**

**Base case** ($n = 1$):

LHS $= 1$. RHS $= \dfrac{1 \times 2}{2} = 1$. ✓

**Inductive hypothesis:** Assume true for $n = m$:

$$1 + 2 + \cdots + m = \frac{m(m+1)}{2}$$

**Inductive step:** Prove true for $n = m + 1$, i.e., show:

$$1 + 2 + \cdots + m + (m+1) = \frac{(m+1)(m+2)}{2}$$

Starting from the LHS and using the hypothesis:

$$\sum_{k=1}^{m+1} k = \underbrace{\sum_{k=1}^{m} k}_{\displaystyle= \frac{m(m+1)}{2}} + (m+1) = \frac{m(m+1)}{2} + (m+1) = (m+1)\left(\frac{m}{2} + 1\right) = \frac{(m+1)(m+2)}{2}$$

This is the required RHS. ✓

**Conclusion:** By the principle of mathematical induction, the result holds for all integers $n \geq 1$. $\square$

## Example 2 — Divisibility proof

**Prove that $5^n - 1$ is divisible by 4 for all integers $n \geq 1$.**

**Base case** ($n = 1$):

$5^1 - 1 = 4$, which is divisible by 4. ✓

**Inductive hypothesis:** Assume true for $n = m$:

$$5^m - 1 = 4q \quad \text{for some integer } q$$

Equivalently, $5^m = 4q + 1$.

**Inductive step:** Show $4 \mid (5^{m+1} - 1)$.

$$5^{m+1} - 1 = 5 \cdot 5^m - 1 = 5(4q + 1) - 1 = 20q + 5 - 1 = 20q + 4 = 4(5q + 1)$$

Since $5q + 1$ is an integer, $5^{m+1} - 1$ is divisible by 4. ✓

**Conclusion:** By the principle of mathematical induction, $4 \mid (5^n - 1)$ for all integers $n \geq 1$. $\square$

## Example 3 — Inequality proof

**Prove that $2^n \geq n + 1$ for all integers $n \geq 1$.**

**Base case** ($n = 1$):

$2^1 = 2 \geq 1 + 1 = 2$. ✓

**Inductive hypothesis:** Assume true for $n = m$: $2^m \geq m + 1$.

**Inductive step:** Show $2^{m+1} \geq (m+1) + 1 = m + 2$.

$$2^{m+1} = 2 \cdot 2^m \geq 2(m + 1) = 2m + 2$$

Now, for $m \geq 1$: $2m + 2 = m + (m + 2) \geq m + 2$ (since $m \geq 0$).

Therefore $2^{m+1} \geq m + 2$. ✓

**Conclusion:** By the principle of mathematical induction, $2^n \geq n + 1$ for all integers $n \geq 1$. $\square$

> **Common mistake:** Writing "assume $P(n)$ is true" without specifying the value. Always write "assume $P(m)$ is true" (or "assume true for $n = m$") to make clear that $m$ is a fixed but arbitrary integer — not the variable you're trying to prove for.
